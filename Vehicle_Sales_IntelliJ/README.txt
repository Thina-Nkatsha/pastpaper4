VEHICLE SALES JAVA PROGRAM

Open VehicleSales.java in IntelliJ IDEA and run the main method.

The program uses a two-dimensional array to store the January, February
and March sales for SUVs, Coupes, Sedans and Vans.

It displays:
- The vehicle type sales report
- Total sales for each vehicle type
- Total sales for each month
- GOLD status when monthly sales are 100 or more
- SILVER status when monthly sales are less than 100
